## 🎯 Реализованные методы

### Метод 1: getAllCountries()
```swift
func getAllCountries(completion: @escaping (Result<[Country], Error>) -> Void)
```
Получает список всех стран из REST Countries API

### Метод 2: searchCountries(by name:)
```swift
func searchCountries(by name: String, completion: @escaping (Result<[Country], Error>) -> Void)
```
Поиск стран по названию

### Метод 3: getCountriesByRegion(_ region:)
```swift
func getCountriesByRegion(_ region: String, completion: @escaping (Result<[Country], Error>) -> Void)
```
Фильтрация стран по региону (Europe, Asia, Americas и т.д.)

### Метод 4: getCountry(by code:)
```swift
func getCountry(by code: String, completion: @escaping (Result<Country, Error>) -> Void)
```
Получение деталей страны по коду (US, IT, FR и т.д.)

## 🏗️ Архитектура Moya

### TargetType
```swift
enum CountriesTarget: TargetType {
    case allCountries
    case searchByName(String)
    case filterByRegion(String)
    case getByCode(String)
}
```

### Provider
```swift
private let provider = MoyaProvider<CountriesTarget>(plugins: [
    NetworkLoggerPlugin(configuration: .init(logOptions: .verbose))
])
```

### Codable Models
```swift
struct Country: Codable {
    let name: CountryName
    let cca2: String?
    let region: String?
    let flags: CountryFlags?
    // ...
}
```

1. **Откройте приложение**
2. **Перейдите на экран TheMealDB**
3. **Увидите две секции:**
   - **Categories** - категории блюд (существующее)
   - **Filter by Country** - страны (НОВОЕ!)
4. **Выберите страну** - например, Italy 🇮🇹
5. **Рецепты отфильтруются** по выбранной стране
6. **В заголовке** отобразится флаг и название
