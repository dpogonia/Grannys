## 1. Strategy (Стратегия)

### Где найти?
**Файл:** `Granny's Recipe Keeper/Models/Recipe/BehavioralPatternsExamples.swift`

**Строки:** 14-169

### Что делает?
Позволяет сортировать рецепты разными способами, легко меняя алгоритм сортировки в runtime.

### Реализованные стратегии:
1. **SortByNameStrategy** - по имени (A-Z)
2. **SortByNameDescendingStrategy** - по имени (Z-A)
3. **SortByDateNewestStrategy** - по дате (новые первые)
4. **SortByDateOldestStrategy** - по дате (старые первые)
5. **SortByCookingTimeStrategy** - по времени приготовления (быстрые первые)
6. **SortByCaloriesStrategy** - по калориям (меньше калорий первыми)
7. **SortByDifficultyStrategy** - по сложности (легкие первыми)
8. **SortByFavoritesStrategy** - избранные первыми

### Как показать?

#### Способ 1: Через код
Добавьте в `SceneDelegate.swift` в методе `scene(_:willConnectTo:options:)`:

```swift
#if DEBUG
    // Демонстрация Strategy паттерна
    let examples = BehavioralPatternsExamples()
    
    print("\n=== STRATEGY PATTERN DEMO ===\n")
    
    // Получить тестовые рецепты
    let recipes = RecipesRepository.mockRecipes()
    print("📚 Всего рецептов: \(recipes.count)\n")
    
    // Создать сортировщик
    let sorter = RecipeSorter(strategy: SortByNameStrategy())
    
    // Попробовать разные стратегии
    let strategies = RecipeSortStrategyManager.shared.getAllStrategies()
    
    for strategy in strategies {
        sorter.setStrategy(strategy)
        let sorted = sorter.sort(recipes: recipes)
        
        print("📊 \(strategy.name):")
        print("   Первый рецепт: \(sorted.first?.name ?? "N/A")")
        print("   Последний рецепт: \(sorted.last?.name ?? "N/A")\n")
    }
#endif
```

#### Способ 2: Готовые примеры
```swift
let examples = BehavioralPatternsExamples()
examples.strategyExample1_SortByName()          // Простая сортировка
examples.strategyExample2_ChangingStrategy()    // Смена стратегии
examples.strategyExample3_AllStrategies()       // Все стратегии
```

### Ключевые классы:
```swift
protocol RecipeSortStrategy           // Протокол стратегии
class RecipeSorter                    // Контекст
class RecipeSortStrategyManager       // Менеджер стратегий
```

## 2. Memento (Хранитель)

### Где найти?
**Файл:** `Granny's Recipe Keeper/Models/Recipe/BehavioralPatternsExamples.swift`

**Строки:** 238-327

### Что делает?
Сохраняет и восстанавливает состояние фильтров (выбранные теги, сложность, стратегия сортировки).

### Как показать?

#### Способ 1: Через код
```swift
#if DEBUG
    print("\n=== MEMENTO PATTERN DEMO ===\n")
    
    let filterState = RecipeFilterState()
    let caretaker = RecipeFilterCaretaker.shared
    
    // 1. Установить фильтры
    filterState.applyFilters(
        tags: ["Vegetarian", "Quick"],
        difficulty: "easy",
        sortIndex: 2
    )
    print("✅ Установлены фильтры:")
    print("   Теги: \(filterState.selectedTags)")
    print("   Сложность: \(filterState.selectedDifficulty ?? "нет")")
    print("   Сортировка: \(filterState.sortStrategyIndex)\n")
    
    // 2. Сохранить состояние
    let memento = filterState.createMemento()
    caretaker.saveMemento(memento)
    print("💾 Состояние сохранено\n")
    
    // 3. Изменить фильтры
    filterState.applyFilters(
        tags: ["Sweet"],
        difficulty: "hard",
        sortIndex: 5
    )
    print("🔄 Фильтры изменены:")
    print("   Теги: \(filterState.selectedTags)")
    print("   Сложность: \(filterState.selectedDifficulty ?? "нет")\n")
    
    // 4. Восстановить из Memento
    if let savedMemento = caretaker.getLastMemento() {
        filterState.restore(from: savedMemento)
        print("↩️  Состояние восстановлено:")
        print("   Теги: \(filterState.selectedTags)")
        print("   Сложность: \(filterState.selectedDifficulty ?? "нет")")
        print("   Сортировка: \(filterState.sortStrategyIndex)\n")
    }
#endif
```

#### Способ 2: Готовые примеры
```swift
let examples = BehavioralPatternsExamples()
examples.mementoExample1_SaveAndRestore()   // Сохранение и восстановление
examples.mementoExample2_MultipleStates()   // Множественные состояния
```

### Ключевые классы:
```swift
struct RecipeFilterMemento           // Снимок состояния
class RecipeFilterState             // Originator
class RecipeFilterCaretaker         // Caretaker
```

## 3. Observer (Наблюдатель)

### Где найти?
Паттерн реализован через **Delegate** во многих местах:

1. **RecipeEditViewController.swift** (строки 10-13, 280-282)
2. **FilterViewController.swift** (строки 10-14, 147-149)
3. **RecipesViewController.swift** (строки 614-617)

### Что делает?
Уведомляет контроллеры об изменениях (сохранение рецепта, применение фильтров и т.д.)

### Как показать?

#### Визуальная демонстрация:
1. Запустите приложение
2. Откройте любой рецепт
3. Нажмите Edit
4. Измените название или ингредиенты
5. Нажмите ✓ (Save)
6. **Наблюдайте:** список рецептов автоматически обновится

**Это Observer паттерн в действии!**

#### Где происходит:
```swift
// В RecipeEditViewController:
delegate?.didSaveRecipe()  // ✅ Уведомление наблюдателей

// В RecipesViewController:
func didSaveRecipe() {
    loadRecipes()  // ✅ Реакция на уведомление
}
```

### Примеры делегатов в проекте:
- `RecipeEditViewControllerDelegate` - уведомление о сохранении
- `FilterViewControllerDelegate` - уведомление о фильтрах
- `CategoriesViewControllerDelegate` - уведомление о категории
- `RecipeDetailViewControllerDelegate` - уведомление об обновлении/удалении
- `UnsplashImageSearchViewControllerDelegate` - уведомление о выборе изображения

## 4. Template Method (Шаблонный метод)

### Где найти?
**Файл:** `Granny's Recipe Keeper/Models/Recipe/BehavioralPatternsExamples.swift`

**Строки:** 435-584

### Что делает?
Определяет общий алгоритм обработки данных из API, позволяя подклассам переопределять отдельные шаги.

### Как показать?

#### Способ 1: Через код
```swift
#if DEBUG
    print("\n=== TEMPLATE METHOD PATTERN DEMO ===\n")
    
    // Создать процессор для TheMealDB
    let processor = TheMealDBDataProcessor(category: "Dessert")
    
    print("🌐 Запуск обработки данных из TheMealDB API...")
    print("📂 Категория: Dessert\n")
    
    processor.processData { result in
        switch result {
        case .success(let recipes):
            print("✅ Успешно обработано \(recipes.count) рецептов\n")
            print("📝 Первые 3 рецепта:")
            for recipe in recipes.prefix(3) {
                print("   - \(recipe.name)")
            }
        case .failure(let error):
            print("❌ Ошибка: \(error.localizedDescription)")
        }
    }
    
    // Подождать завершения
    Thread.sleep(forTimeInterval: 3)
#endif
```

#### Способ 2: Готовый пример
```swift
let examples = BehavioralPatternsExamples()
examples.templateMethodExample()
```

### Шаги алгоритма (Template Method):
1. `validateBeforeLoad()` - валидация
2. `fetchDataFromAPI()` - загрузка из API
3. `processRawData()` - обработка данных
4. `validateProcessedData()` - валидация результата
5. `convertToRecipes()` - конвертация в модель
6. `finalizeProcessing()` - финализация
7. `handleError()` - обработка ошибок

### Ключевые классы:
```swift
class APIDataProcessor              // Абстрактный класс с шаблонным методом
class TheMealDBDataProcessor        // Конкретная реализация
```

## 5. Command (Команда)

### Где найти?
1. **ImageLoadOperation.swift** (строки 11-133)
2. **BehavioralPatternsExamples.swift** (строки 650-782)

### Что делает?
Инкапсулирует операции как объекты, поддерживает отмену и постановку в очередь.

### Как показать?

#### Способ 1: Image Loading Command (через UI)
1. Запустите приложение
2. Откройте список рецептов
3. Прокрутите вниз - изображения загружаются через Command паттерн
4. Прокрутите быстро - ненужные загрузки отменяются

**Это Command паттерн с отменой операций!**

#### Способ 2: Recipe Commands (через код)
```swift
#if DEBUG
    print("\n=== COMMAND PATTERN DEMO ===\n")
    
    // Получить тестовый рецепт
    guard let recipe = RecipesRepository.mockRecipes().first else { return }
    
    // Создать invoker
    let invoker = RecipeCommandInvoker()
    
    // 1. Добавить в избранное
    print("1️⃣ Выполняем команду: Добавить в избранное")
    let addCommand = AddToFavoritesCommand(recipe: recipe)
    invoker.executeCommand(addCommand)
    
    // 2. Архивировать
    print("\n2️⃣ Выполняем команду: Архивировать")
    let archiveCommand = ArchiveRecipeCommand(recipe: recipe)
    invoker.executeCommand(archiveCommand)
    
    print("\n📚 Команд в истории: \(invoker.getHistoryCount())")
    
    // 3. Отменить последнюю команду
    print("\n↩️  Отменяем последнюю команду")
    invoker.undoLastCommand()
    
    print("📚 Команд в истории: \(invoker.getHistoryCount())")
#endif
```

#### Способ 3: Готовый пример
```swift
let examples = BehavioralPatternsExamples()
examples.commandExample()
```

### Реализованные команды:
**Для изображений:**
- `ImageLoadOperation` - загрузка изображения
- Поддержка отмены через `cancel()`

**Для рецептов:**
- `AddToFavoritesCommand` - добавить в избранное
- `RemoveFromFavoritesCommand` - удалить из избранного
- `ArchiveRecipeCommand` - архивировать

### Ключевые классы:
```swift
protocol RecipeCommand              // Интерфейс команды
class RecipeCommandInvoker          // Invoker с историей для Undo
class ImageLoadOperation            // Команда загрузки изображения
```
