## 🎯 Как использовать

### В TheMealDBViewController:

1. **Откройте экран TheMealDB**
2. **Увидите три коллекции фильтров:**
   ```
   [Categories: All Recipes | Beef | Breakfast | ...]
   
   Filter by Country
   [Countries: 🌍 All Countries | 🇺🇸 American | 🇬🇧 British | ...]
   
   Filter by Ingredient
   [Ingredients: 🥘 All Ingredients | 🍗 Chicken | 🥩 Beef | ...]
   ```

3. **Выберите ингредиент** (например, 🍗 Chicken)
4. **Рецепты отфильтруются** - покажутся только блюда с курицей
5. **В заголовке** появится: "TheMealDB - 🥘 Chicken"

---

### В FilterViewController (экран Filters):

1. **Откройте Filters** (кнопка в главном меню)
2. **Увидите три секции:**
   - Difficulty ▶ (Easy, Medium, Hard)
   - Tags ▶ (список тегов)
   - **Ingredients ▶** (НОВОЕ!)

3. **Раскройте "Ingredients"** (tap на заголовок)
4. **Выберите ингредиенты** (галочки)
5. **Apply** (✓) - фильтры применятся

## 🔄 Логика работы фильтров

### Взаимодействие фильтров:

```
При выборе КАТЕГОРИИ:
  → Сброс страны и ингредиента
  → Загрузка рецептов по категории

При выборе СТРАНЫ:
  → Сброс категории и ингредиента
  → Загрузка рецептов по стране

При выборе ИНГРЕДИЕНТА:
  → Сброс категории и страны
  → Загрузка рецептов по ингредиенту

При выборе "All":
  → Сброс всех фильтров
  → Загрузка случайных рецептов
```
