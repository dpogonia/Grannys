1. RecipesRepository (Фасад для Core Data)
   📁 Файл: Granny's Recipe Keeper/Models/Recipe/RecipesRepository.swift
   📍 Строки: 12-48 (описание паттерна Facade)
   📍 Строки: 49-300+ (реализация фасада)
   🔍 Поиск: "ПАТТЕРН 1: FACADE" или "RecipesRepository"

   Методы фасада (упрощенный API):
   - getAllRecipes(archived:) → [Recipe]
   - getRecipes(in:archived:) → [Recipe]
   - searchRecipes(query:in:) → [Recipe]
   - getFavoriteRecipes() → [Recipe]
   - saveRecipe(_:)
   - deleteRecipe(_:)
   - getAllCategories() → [Category]
   - saveCategory(_:)
   - deleteCategory(_:)
   
   Что скрывает фасад:
   - NSManagedObjectContext
   - NSFetchRequest
   - NSPredicate
   - Entity ↔ Model маппинг
   - Связи между сущностями
   - Обработка ошибок Core Data

ПАТТЕРН 2: ADAPTER (АДАПТЕР) - 2 РЕАЛИЗАЦИИ
───────────────────────────────────────────────────────────────────────────────

1. TheMealDBRecipeAdapter
   📁 Файл: Granny's Recipe Keeper/Models/Recipe/RecipeAdapters.swift
   📍 Строки: 1-50 (описание паттерна Adapter)
   📍 Строки: 58-150 (реализация TheMealDBRecipeAdapter)
   🔍 Поиск: "class TheMealDBRecipeAdapter" или "ПАТТЕРН 2: ADAPTER"

   Назначение:
   - Преобразует TheMealDBRecipe (20 полей ингредиентов) → Recipe
   - Преобразует строку тегов → массив тегов
   - Унифицирует формат данных из TheMealDB API

   Использование:
   - let adapter = TheMealDBRecipeAdapter(mealDBRecipe: mealDB)
   - let recipe = adapter.adapt()
   - Или: let recipe = mealDBRecipe.toRecipe()

2. GenericRecipeAdapter
   📁 Файл: Granny's Recipe Keeper/Models/Recipe/RecipeAdapters.swift
   📍 Строки: 152-250 (реализация GenericRecipeAdapter)
   🔍 Поиск: "class GenericRecipeAdapter"

   Назначение:
   - Преобразует APIRecipe → Recipe
   - Преобразует APIIngredient (amount: Double) → Ingredient (amount: String)
   - Унифицирует формат данных из Generic Recipe API

   Использование:
   - let adapter = GenericRecipeAdapter(apiRecipe: api)
   - let recipe = adapter.adapt()
   - Или: let recipe = apiRecipe.toRecipe()

3. RecipeAdapterFactory (Фабрика адаптеров)
   📁 Файл: Granny's Recipe Keeper/Models/Recipe/RecipeAdapters.swift
   📍 Строки: 252-270
   🔍 Поиск: "class RecipeAdapterFactory"

   Назначение:
   - Упрощает создание правильного адаптера
   - Единый интерфейс для разных типов данных

   Использование:
   - let adapter = RecipeAdapterFactory.makeAdapter(from: mealDB)
   - let adapter = RecipeAdapterFactory.makeAdapter(from: api)
