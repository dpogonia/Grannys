## Как продемонстрировать

### Вариант 1: Через Xcode (рекомендуется)

1. Откройте проект в Xcode
2. Используйте поиск (⌘+Shift+F) и найдите:
   - `ПАТТЕРН 1: SINGLETON` → покажет все 7 реализаций
   - `ПАТТЕРН 2: BUILDER` → покажет реализацию Builder

3. Покажите один из паттернов Singleton (например, CoreDataManager):
   ```swift
   class CoreDataManager {
       static let shared = CoreDataManager()
       private init() {}
   }
   ```

4. Покажите паттерн Builder (RecipeBuilder):
   ```swift
   let recipe = RecipeBuilder(name: "Cheesecake")
       .with(instructions: "Mix ingredients...")
       .with(cookingTime: 60)
       .addIngredient(name: "Cream cheese", amount: "500g")
       .addCategory(Category(name: "Desserts", isDefault: true))
       .build()
   ```

5. Запустите примеры (опционально):
   ```swift
   let examples = CreationalPatternsExamples()
   examples.runAllExamples()
   ```

## Ключевые моменты для объяснения

### Singleton (Одиночка)
**Где используется:** 7 мест
- CoreDataManager - единый контекст Core Data
- ImageCache - единый кэш изображений
- TagsManager - управление тегами
- RecipesRepository - репозиторий данных
- NetworkService - сетевой слой
- TheMealDBService - API сервис
- ImageLoadQueueManager - очередь загрузки

**Почему Singleton:**
- Предотвращает конфликты данных
- Эффективное использование ресурсов
- Единый источник правды
- Простой доступ из любой части приложения

### Builder (Строитель)
**Где используется:** Recipe (13 параметров)

**Почему Builder:**
- У Recipe много параметров (13 штук)
- Большинство параметров опциональны
- Builder делает код читаемым и понятным
- Невозможно перепутать порядок параметров

**Пример преимущества:**

❌ Без Builder (сложно):
```swift
Recipe(id: UUID(), name: "...", recipeInstructions: "...", 
       imageData: nil, imageURL: nil, ingredients: [...], 
       categories: [...], isArchived: false, isFavorite: true, 
       createdAt: Date(), cookingTime: 15, servings: 4, 
       difficulty: "easy", calories: 250, tags: [...])
```

✅ С Builder (просто):
```swift
RecipeBuilder(name: "...")
    .with(instructions: "...")
    .with(cookingTime: 15)
    .addIngredient(name: "...", amount: "...")
    .build()
```

## Частые вопросы

**Q: Почему именно эти паттерны?**
A: 
- Singleton уже активно использовался в проекте (7 мест)
- Builder идеально подходит для Recipe (13 параметров)
- Оба паттерна имеют практическое применение, а не "для галочки"

**Q: Можно было выбрать другие паттерны?**
A: Да, но эти паттерны:
- Уже применялись в коде (Singleton)
- Решают реальную проблему (Builder для сложного объекта)
- Соответствуют best practices из лекции

**Q: Где находятся комментарии к паттернам?**
A: 
- Поиск в Xcode: "ДОМАШНЕЕ ЗАДАНИЕ: ПОРОЖДАЮЩИЕ ПАТТЕРНЫ"
- Все 8 файлов с реализацией содержат подробные комментарии
