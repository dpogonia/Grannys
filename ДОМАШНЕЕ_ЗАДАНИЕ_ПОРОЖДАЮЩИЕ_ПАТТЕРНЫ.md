### 1. SINGLETON (ОДИНОЧКА) - 40 баллов

**Описание паттерна:**
Singleton обеспечивает создание только одного экземпляра класса и предоставляет глобальную точку доступа к нему.

**Применение в проекте:**

### 2. BUILDER (СТРОИТЕЛЬ) - 40 баллов

**Описание паттерна:**
Builder позволяет создавать сложные объекты пошагово, устанавливая только необходимые параметры. Особенно полезен для объектов с большим количеством параметров.

**Применение в проекте:**
Паттерн Builder реализован для структуры `Recipe`, которая имеет **13 параметров**, что делает её идеальным кандидатом для этого паттерна.

#### Реализация: RecipeBuilder
**Файл:** `Granny's Recipe Keeper/Models/Recipe/Recipe.swift`
- **Строки:** 270-450
- **Назначение:** Пошаговое создание объектов Recipe
- **Преимущества:** Читаемость кода, гибкость, упрощение работы со сложными объектами

**Структура Recipe (13 параметров):**
```swift
struct Recipe {
    let id: UUID
    var name: String
    var recipeInstructions: String?
    var imageData: Data?
    var imageURL: String?
    var ingredients: [Ingredient]
    var categories: [Category]
    var isArchived: Bool
    var isFavorite: Bool
    var createdAt: Date
    var cookingTime: Int?
    var servings: Int?
    var difficulty: String?
    var calories: Int?
    var tags: [String]
}
```

**Реализация Builder:**

```swift
class RecipeBuilder {
    // Инициализатор с обязательным параметром
    init(name: String) {
        self.name = name
    }
    
    // Методы для установки параметров (fluent interface)
    func with(instructions: String) -> RecipeBuilder
    func with(cookingTime: Int) -> RecipeBuilder
    func with(servings: Int) -> RecipeBuilder
    func with(difficulty: String) -> RecipeBuilder
    func with(calories: Int) -> RecipeBuilder
    
    // Методы для добавления элементов в коллекции
    func addIngredient(name: String, amount: String?) -> RecipeBuilder
    func addCategory(_ category: Category) -> RecipeBuilder
    func addTag(_ tag: String) -> RecipeBuilder
    
    // Методы для установки флагов
    func markAsFavorite(_ isFavorite: Bool = true) -> RecipeBuilder
    func markAsArchived(_ isArchived: Bool = true) -> RecipeBuilder
    
    // Финальный метод создания объекта
    func build() -> Recipe
}
```

**Примеры использования:**

1. **Простой рецепт:**
```swift
let recipe = RecipeBuilder(name: "Omelette")
    .with(instructions: "Beat eggs, cook in pan")
    .with(cookingTime: 10)
    .with(servings: 2)
    .with(difficulty: "easy")
    .build()
```

2. **Сложный рецепт с ингредиентами:**
```swift
let recipe = RecipeBuilder(name: "Chocolate Cake")
    .with(instructions: "Mix ingredients, bake")
    .with(cookingTime: 45)
    .with(servings: 8)
    .with(difficulty: "medium")
    .with(calories: 350)
    .addIngredient(name: "Flour", amount: "200g")
    .addIngredient(name: "Cocoa", amount: "50g")
    .addIngredient(name: "Sugar", amount: "150g")
    .addCategory(Category(name: "Desserts", isDefault: true))
    .addTag("Sweet")
    .addTag("Chocolate")
    .markAsFavorite()
    .build()
```

3. **Создание из существующего рецепта (для редактирования):**
```swift
let editedRecipe = Recipe.builder(from: originalRecipe)
    .with(servings: 6)
    .addIngredient(name: "Parmesan", amount: "100g")
    .addTag("Italian")
    .build()
```

**Преимущества Builder по сравнению с обычным инициализатором:**

❌ **БЕЗ BUILDER:**
```swift
let recipe = Recipe(
    id: UUID(),
    name: "Pancakes",
    recipeInstructions: "Mix and cook",
    imageData: nil,
    imageURL: nil,
    ingredients: [...],
    categories: [...],
    isArchived: false,
    isFavorite: true,
    createdAt: Date(),
    cookingTime: 15,
    servings: 4,
    difficulty: "easy",
    calories: 250,
    tags: ["Quick", "Easy"]
)
// Проблемы: 13 параметров, сложно читать, легко ошибиться
```

✅ **С BUILDER:**
```swift
let recipe = RecipeBuilder(name: "Pancakes")
    .with(instructions: "Mix and cook")
    .with(cookingTime: 15)
    .with(servings: 4)
    .with(difficulty: "easy")
    .with(calories: 250)
    .addIngredient(name: "Flour", amount: "200g")
    .addIngredient(name: "Milk", amount: "300ml")
    .addCategory(Category(name: "Breakfast", isDefault: true))
    .addTag("Quick")
    .markAsFavorite()
    .build()
// Преимущества: Читаемо, понятно, невозможно перепутать параметры
```

## Соответствие требованиям лекции

### 1. Singleton (Одиночка)
✅ **Когда использовать (из лекции):**
- Нужен единственный общий ресурс/реестр для всего приложения
- Кеш, логирование, аналитика ✓ (ImageCache, NetworkService)
- Доступ должен быть простым и единым ✓ (все 7 реализаций)

✅ **Реализация (из лекции):**
- `static let shared` - единственный экземпляр ✓
- `private init()` - запрещает создание извне ✓
- Все пользователи обращаются через `.shared` ✓

### 2. Builder (Строитель)
✅ **Когда использовать (из лекции):**
- Сложная инициализация: много параметров ✓ (13 параметров в Recipe)
- Часть опциональны ✓ (10 из 13 параметров опциональны)
- Читаемость "по шагам" ✓ (fluent interface)

✅ **Реализация (из лекции):**
- Builder хранит промежуточное состояние ✓
- Методы возвращают Builder (immutable style) ✓
- `build()` создаёт финальный объект ✓

## Архитектурные преимущества

### Singleton в проекте:
1. **Централизация ресурсов** - единая точка доступа к данным и сервисам
2. **Предотвращение конфликтов** - особенно важно для Core Data
3. **Эффективность** - переиспользование соединений и ресурсов
4. **Упрощение кода** - легкий доступ из любой части приложения

### Builder в проекте:
1. **Читаемость** - пошаговое создание объектов
2. **Гибкость** - можно задать только нужные параметры
3. **Безопасность** - невозможно перепутать порядок параметров
4. **Расширяемость** - легко добавлять новые параметры
