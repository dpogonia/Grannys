# Инструкция по запуску домашнего задания Moya

## Шаги для завершения установки

### 1. Откройте проект в Xcode
```bash
open "Granny's Recipe Keeper.xcodeproj"
```

### 2. Добавьте новые файлы в проект

В Xcode нужно добавить следующие файлы:

#### Файл 1: CountriesAPI.swift
📂 **Путь:** `Granny's Recipe Keeper/Network Model & Views/CountriesAPI.swift`

**Как добавить:**
1. В Xcode найдите папку `Network Model & Views` в навигаторе
2. Правый клик на папке → **Add Files to "Granny's Recipe Keeper"...**
3. Найдите файл `CountriesAPI.swift` в папке `Network Model & Views`
4. ✅ Убедитесь, что галочка **"Copy items if needed"** СНЯТА (файл уже в проекте)
5. ✅ Убедитесь, что галочка **"Add to targets"** установлена для `Granny's Recipe Keeper`
6. Нажмите **Add**

#### Файл 2: CountryCollectionViewCell.swift
📂 **Путь:** `Granny's Recipe Keeper/Views/Countries/CountryCollectionViewCell.swift`

**Как добавить:**
1. В Xcode найдите папку `Views` в навигаторе
2. Правый клик на папке `Views` → **Add Files to "Granny's Recipe Keeper"...**
3. Найдите папку `Countries` и файл `CountryCollectionViewCell.swift`
4. ✅ Убедитесь, что галочка **"Copy items if needed"** СНЯТА
5. ✅ Убедитесь, что галочка **"Add to targets"** установлена
6. Нажмите **Add**

### 3. Проверьте зависимости

Moya уже добавлена в проект! Убедитесь, что она подключена:

1. В Xcode откройте **Project Navigator** (⌘+1)
2. Выберите проект (синяя иконка "Granny's Recipe Keeper")
3. Перейдите на вкладку **Package Dependencies**
4. Должны быть видны:
   - ✅ Moya @ 15.0.3
   - ✅ Alamofire @ 5.11.0
   - ✅ SwiftLint @ 0.63.1
   - ✅ RxSwift @ 6.10.1

### 4. Соберите проект

```
Product → Clean Build Folder (⇧⌘K)
Product → Build (⌘B)
```

Или в терминале:
```bash
cd "/Users/dpogonia/Documents/Swift/Projects/Main/Grannys"
xcodebuild -project "Granny's Recipe Keeper.xcodeproj" -scheme "Granny's Recipe Keeper" -destination 'generic/platform=iOS' clean build
```

### 5. Запустите приложение

1. Выберите симулятор (например, iPhone 16 Pro)
2. Нажмите **Run** (⌘R)
3. Откройте экран **TheMealDB**
4. Вы увидите две коллекции:
   - **Categories** (существующие)
   - **Filter by Country** (НОВОЕ! 🌍)

### 6. Проверьте функционал

1. ✅ Выберите любую страну из списка "Filter by Country"
2. ✅ Рецепты отфильтруются по выбранной стране
3. ✅ В заголовке появится флаг и название страны
4. ✅ Можно вернуться к "All Countries" для сброса фильтра

## Возможные проблемы и решения

### ❌ Ошибка: "Cannot find 'MoyaProvider' in scope"
**Решение:** Убедитесь, что Moya добавлена в зависимости:
1. Project → Package Dependencies → + → https://github.com/Moya/Moya.git
2. Version: 15.0.0 или выше
3. Пересоберите проект (⇧⌘K → ⌘B)

### ❌ Ошибка: "No such module 'Moya'"
**Решение:** 
1. Закройте Xcode
2. Удалите папку `DerivedData`:
   ```bash
   rm -rf ~/Library/Developer/Xcode/DerivedData
   ```
3. Откройте проект заново
4. Пересоберите

### ❌ Файлы не видны в Xcode
**Решение:**
1. В Finder убедитесь, что файлы существуют
2. В Xcode: File → Add Files to "Granny's Recipe Keeper"...
3. Выберите файлы вручную

### ❌ Страны не загружаются
**Решение:**
- Проверьте интернет-соединение
- REST Countries API не требует ключей
- Проверьте консоль Xcode на наличие ошибок
