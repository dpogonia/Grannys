## 💡 Ключевые особенности

### Почему именно эти паттерны?

1. **Singleton:**
   - Уже активно использовался в проекте (7 мест)
   - Имеет практическое применение
   - Критически важен для Core Data, кэша, сетевого слоя

2. **Builder:**
   - Recipe имеет 13 параметров → идеален для Builder
   - Решает реальную проблему сложности создания объектов
   - Улучшает читаемость кода

### Соответствие лекции

✅ **Singleton (из презентации):**
- `static let shared` - единственный экземпляр
- `private init()` - запрет создания извне
- Применение для кэша, логирования, сервисов

✅ **Builder (из презентации):**
- Множество параметров (13 штук)
- Промежуточное состояние в Builder
- Методы возвращают Builder (fluent interface)
- `build()` создаёт финальный объект
