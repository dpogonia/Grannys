**Где НЕ используется:**

**Текущее поведение:**
- Пользователь выбрал фильтры
- Закрыл FilterViewController
- Открыл снова - фильтры сброшены ❌

**Рекомендация:**
🔧 **ИНТЕГРИРОВАТЬ MEMENTO В FILTERVIEWCONTROLLER**

Как реализовать:

```swift
// В FilterViewController.swift

override func viewDidLoad() {
    super.viewDidLoad()
    // ... существующий код ...
    
    // Восстановить последнее состояние
    restoreLastFilterState()
}

private func restoreLastFilterState() {
    let caretaker = RecipeFilterCaretaker.shared
    if let lastMemento = caretaker.getLastMemento() {
        // Восстановить фильтры
        selectedTags = lastMemento.selectedTags
        selectedDifficulty = lastMemento.selectedDifficulty
        // Обновить UI
        tableView.reloadData()
    }
}

@objc private func didTapApplyButton() {
    // Сохранить состояние перед применением
    let filterState = RecipeFilterState()
    filterState.applyFilters(
        tags: selectedTags, 
        difficulty: selectedDifficulty, 
        sortIndex: 0
    )
    
    let memento = filterState.createMemento()
    RecipeFilterCaretaker.shared.saveMemento(memento)
    
    // Применить фильтры
    delegate?.didApplyFilters(selectedTags: selectedTags, selectedDifficulty: selectedDifficulty)
    navigationController?.dismiss(animated: true)
}
```

**ВАЖНО:** Паттерн готов, нужна только интеграция!
